# Dlya Adminov

Простое приложение для Windows: учёт товаров и услуг PS, скидка, история смен и отчёты Excel. Работает без интернета. Интерфейс полностью на русском.

## Как установить

1. Откройте [страницу скачивания](https://github.com/griashagalkin7-eng/Dlya-Adminov/releases/latest).
2. В разделе **Assets** скачайте **Dlya-Adminov-Setup-1.0.0.exe**. Если версия изменилась — файл с тем же названием и новой версией.
3. Запустите файл. Выберите папку установки и нажмите **Установить**.
4. Открывайте программу через ярлык **Dlya Adminov** на рабочем столе или в меню **Пуск**.

Нужна **Windows 10 или 11, 64 бит (x64)**. Интернет нужен для скачивания; после установки можно работать без него. Node.js, Excel и другие программы для запуска Dlya Adminov устанавливать не нужно. Для просмотра выгруженного XLSX подойдёт Excel или другой редактор таблиц.

Если установщик ещё не появился, откройте [Actions → Windows installer](https://github.com/griashagalkin7-eng/Dlya-Adminov/actions/workflows/windows.yml) и дождитесь зелёной отметки сборки. Готовый файл появится в Releases и в артефакте **Dlya-Adminov-Windows** этой сборки. Если сборка красная, установщика этой версии ещё нет.

Программа пока без цифровой подписи. Если Windows показывает «Система Windows защитила ваш компьютер», проверьте, что файл скачан именно из этого репозитория; затем **Подробнее → Выполнить в любом случае**, если такая кнопка доступна.

**Code → Download ZIP** скачивает исходный код, а не готовую программу. Для обычной установки используйте файл `.exe` со страницы Releases.

## Первые настройки

1. Откройте **Настройки**.
2. В блоке **Товары** нажмите **Добавить**, введите название и исходную цену, нажмите **Сохранить**.
3. При желании добавьте названия услуг в **Заготовки PS**. Их цены вводятся при каждом добавлении в учёт.
4. В поле **Общий дисконт** задайте процент и нажмите **Сохранить**. По умолчанию — **0%**.

Для товаров скидка применяется автоматически. Для PS она включается отдельно кнопкой **Дисконт**. Все цены — целые рубли; результат скидки округляется обычным способом до рубля **за единицу товара**, после чего умножается на количество.

## Как вести учёт

1. В разделе **Учёт** нажмите **Начать учёт**.
2. Проверьте дату и выберите **День** или **Ночь**. Для ночи укажите дату её начала. Дату можно изменить.
3. Во вкладке **Товары** начните вводить название, выберите товар из подсказок, укажите количество и нажмите **Добавить**. Количество по умолчанию — 1.
4. Во вкладке **PS / услуги** введите название (например, `ТВ3 — 1,5 часа`) или выберите заготовку, затем введите **полную сумму услуги**. Если нужна скидка — включите **Дисконт**. Если сумма уже со скидкой, оставьте кнопку выключенной.
5. Исправляйте позиции карандашом, удаляйте корзиной. Итог пересчитывается сразу.

Повторное добавление того же товара с той же ценой увеличивает количество в строке. Если цена или скидка изменилась, создаётся отдельная строка. Цена товара меняется через **Настройки → карандаш → Сохранить** и действует только на новые добавления. Уже добавленные позиции сохраняют прежние цены. Дробную длительность услуги можно написать в названии, например `1,5 часа`; её сумму вводите вручную.

Все изменения сохраняются автоматически на этом компьютере. После закрытия программы или перезагрузки обычным способом учёт остаётся на месте. При следующем запуске можно продолжить его. Если выбрать новый учёт, сначала нужно завершить текущий: одновременно открыт только один.

## Отчёт и завершение

1. Нажмите **Открыть отчёт**.
2. В отчёте показаны все позиции, количество, итоговая цена за единицу, сумма по строке и общий итог. Исходные цены и размер скидки отдельно не выводятся.
3. Кнопка **Скачать XLSX** справа вверху сохраняет отчёт Excel в выбранную папку. Скачивание не завершает учёт.
4. Чтобы продолжить добавления, нажмите **Вернуться в учёт**.
5. Чтобы закончить смену, нажмите **Завершить учёт** и подтвердите. Смена сохранится в истории, статистика обновится. Затем можно начать новую с нулевым итогом.

## История и статистика

- В **Истории** ищите смены по датам и метке день/ночь. За одну дату может быть несколько смен с одной меткой.
- Откройте смену, чтобы посмотреть или скачать её отчёт. Кнопка **Редактировать** позволяет исправлять позиции, добавлять новые и менять дату/смену. Изменения сохраняются сразу; **Готово** закрывает режим редактирования.
- Учёт можно удалить корзиной после подтверждения. Удаление нельзя отменить.
- В **Статистике** выберите месяц: увидите сумму за месяц, разбивку по товарам и PS и итоги по дням. Учитываются только завершённые учёты. Исправление или удаление старого учёта сразу меняет статистику.
- Светлая/тёмная тема переключается кнопкой внизу слева. Выбор сохраняется.

Удаление товара или заготовки из настроек не меняет существующие учёты. Приложение общее для сотрудников: имён и паролей нет. Складские остатки не ведутся.

## Где лежат данные

Данные учёта находятся в **`%APPDATA%\Dlya Adminov\ledger.json`**. Чтобы открыть папку: нажмите **Win + R**, вставьте **`%APPDATA%\Dlya Adminov`**, нажмите Enter.

Данные не находятся в папке распакованного репозитория, поэтому её перемещение не сбрасывает учёт. Обычное обновление установщиком и удаление приложения сохраняют файл данных. Автоматических резервных копий пока нет. При необходимости закройте программу и скопируйте всю папку `Dlya Adminov` на другой носитель. Данные локальны для текущего пользователя Windows.

## Запуск из исходников (для разработки)

Этот раздел нужен, если вы хотите менять код. Для обычной работы достаточно установщика выше.

1. Установите [Node.js 24](https://nodejs.org/).
2. Скачайте репозиторий через **Code → Download ZIP** и распакуйте.
3. Откройте терминал в папке с `package.json`.
4. Выполните:

```bash
npm ci
npm run dev
```

Установка зависимостей требует интернета. `npm run dev` открывает настоящее окно приложения с автоматическим обновлением интерфейса.

Собрать Windows-установщик на Windows x64:

```bash
npm run dist:win
```

Готовый `.exe` появится в папке **release**. Сборка интерфейса — `npm run build`, проверки расчётов, сохранения и XLSX — `npm test`. Проверка основного сценария в настоящем окне Electron — `npm run test:ui` (нужна графическая сессия; использует отдельную временную папку данных).

GitHub Actions собирает установщик после изменений в `main` и публикует его в Releases. Перед выпуском новой версии измените `version` в `package.json` и обновите lock-файл командой `npm install --package-lock-only`.

## Устройство проекта

- `src/` — интерфейс React, светлая и тёмная темы.
- `electron/domain.cjs` — учёт, скидки и проверка входных данных.
- `electron/store.cjs` — локальное сохранение с записью во временный файл и заменой основного после успешной записи.
- `electron/export.cjs` — формирование настоящего XLSX.
- `electron/main.cjs`, `electron/preload.cjs` — окно и ограниченный доступ интерфейса к данным.
- `test/` — проверки денежных расчётов, истории, сохранения и Excel.

При ошибке чтения повреждённый файл не сбрасывается и не перезаписывается: приложение покажет сообщение с папкой данных.
